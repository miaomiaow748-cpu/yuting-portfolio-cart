# YUTING / PORTFOLIO CART

> 我喜欢把复杂的事，变成让人想拿走的东西。

这是王雨婷的创意个人作品集网站。网站把教育背景、实习经历、文化创意项目、营销作品与兴趣经历做成一组可以被“拿走”的商品卡片：浏览者沿着页面滚动，在左右两侧挑选经历，并把感兴趣的内容放进中央购物篮。

## 在线查看

[打开 Yuting / Portfolio Cart](https://miaomiaow748-cpu.github.io/yuting-portfolio-cart/)

## 交互方式

- 向下滚动，浏览两侧依次展开的个人经历与作品卡片。
- 点击卡片，将它放入中央购物篮。
- 再次点击购物篮中的卡片，可以将它放回原位。
- 点击带有抽拉标签的经历，可以展开更具体的内容与图片。
- 在营销作品集与文化创意项目中，可以继续查看文件夹式的图片详情。

## 内容板块

- **Education**：教育背景与学习经历
- **Internships**：名创优品、湖南卫视、美团、新东方等实习经历
- **Creative Works**：文化创意项目与营销作品集
- **Interests**：艺术表演、钢琴、北京国际电影节、北京当代艺术展等兴趣与经历
- **About Me / Pick Me**：关于工作能力、创意能力与 AI 学习能力的个人评价

## 视觉概念

网站以“购物篮”作为作品集隐喻：

- 经历像货架上的商品一样被陈列；
- 浏览者可以主动挑选想了解的内容；
- 购物篮代表一份逐渐被看见、被理解的个人履历；
- 红色购物篮、抽拉卡片、收据与文件夹元素共同构成轻松、有记忆点的视觉语言。

## 技术栈

- HTML
- CSS
- Vanilla JavaScript
- Static assets
- GitHub Pages

项目无需构建工具或后端服务，适合直接作为静态网站部署。

## 本地运行

在项目根目录启动一个静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后打开：

http://localhost:8000
